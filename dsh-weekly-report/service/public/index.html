            怎么准备模板？（新装必看）
            

              
    
                
  1. 配置页「绩效表目录」填一个**已存在**的目录，例如 D:\…\绩效表\2026
    2. 
                
  2. 往这个目录里放**至少一张**《员工月度考核表》.xlsx（名字随意，Excel 的 ~$ 临时文件会被忽略）
    3. 
                
  3. 工作表名最好是「月度考核」；第 7 行起是任务区，下面要有「工作任务考核（60%）」等区块
    4. 
                
  4. 引擎优先挑名字里带「当年当月」的那张当模板，没有就用最新那张；模板本身不会被改动，生成的是当月新表
    5. 
                
  5. 目录为空时：周报照常生成，只提示「还没有可用模板」；点「模板自检」可看现状
    6. 
              

            

          

          

            绩效表 = 本月全部周报内容的合集（同一事项一行，起止时间取并集，格式按模板不变）。
            「查看绩效表」直接在面板里看内容；「核对」会对照本月各周周报逐条比对，缺的自动补进表里。
